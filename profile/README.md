## ¿Qué es madOS?

**madOS** es una distribución Linux basada en Arch Linux, diseñada para ser una experiencia de escritorio moderna, minimalista y centrada en el desarrollo. Construida con Wayland, optimizada para rendimiento y customizable.

### Características Principales

- **Wayland First**: Hyprland y Sway incluidos
- **AI-Integrated**: OpenCode y Ollama incluídos
- **Live USB**: Persistence support
- **Minimalista**: Solo lo esencial
- **Open Source**: 100% transparente

## Tecnologías

- **Distro**: Arch Linux
- **Display Server**: Wayland (Hyprland, Sway)
- **Window Manager**: Hyprland
- **Status Bar**: Waybar
- **AI**: OpenCode, Ollama
- **Build**: mkarchiso
